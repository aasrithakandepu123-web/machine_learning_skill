# machine_learning_skill

# Machine Learning Projects

This folder contains 11 beginner-friendly Machine Learning projects implemented using Python.  
The projects cover data analysis, preprocessing, regression, classification, ensemble learning, and model interpretation.

## Projects

### 1. Titanic Survival — EDA

**File:** `01_titanic_eda.py`

This project performs Exploratory Data Analysis (EDA) on the Titanic dataset.

**Topics covered:**
- Data loading
- Data inspection
- Missing value analysis
- Survival analysis
- Data visualization
- Basic statistics

**Dataset:** Titanic Dataset

---
